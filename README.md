## Featured projects
 
### Personal Finance Manager
Full Stack web application for personal finance management. Users can register, list and delete income and expense transactions, while the application automatically calculates balances and totals.
 
- REST API built with Python and FastAPI
- SQLite persistence
- Front-End built with HTML, CSS and Vanilla JavaScript
- CRUD operations and integration between Front-End and Back-End
`Python` `FastAPI` `SQLite` `JavaScript` `HTML` `CSS` `REST API`
 
### AgroOrbit IA
Academic project focused on intelligent agriculture. The solution explores IoT, environmental indicators and agricultural risk simulation to support data-informed decisions in the field.
 
- Agricultural risk simulation using environmental variables
- Interactive dashboard and field registration
- Concepts involving IoT and remote sensing
`Python` `JavaScript` `HTML` `CSS` `IoT`
 
### Modo Estudante
Academic solution concept developed for a FIAP challenge in partnership with JOVI. It explores the use of AI in the smartphone camera experience to help students capture study materials and turn them into organized learning resources.
 
- Document and text capture assistance
- OCR-based text extraction
- AI-generated study summaries
- Organization of study materials
